## Vibero 稀疏克隆说明（按需扩展）

已取：`ai-chat/`（对话面板全部源码，React18+antd+slate）、
`chrome/.../components/annotation.jsx`（标注卡片）、`xpcom/annotations.js`（标注数据层）、
`xpcom/paperAiDB.js`（Zotero.VibeDB 对话持久化）、`xpcom/reader.js`（ReaderBridge=VibeCard 桥）。

扩展更多文件：
```bash
cd vibero && git sparse-checkout set --no-cone <既有路径> <新增路径>   # blob 按需拉取
```

**关键事实（2026-08-17 勘察）**：
- ai-chat 跑在 iframe，经 `window.parent.Zotero.*` 与主程序通信；
  `Zotero.VibeCard = Zotero.ReaderBridge`（reader.js:2795），委托 `_internalReader.getPlainTextForAIChat()`
- **reader 子模块钉的是上游 zotero/reader@8dc837d，不含 Vibero 定制**——
  reader 侧的 AI 钩子（选区→对话、getPlainTextForAIChat 实现）未开源，只有交互理念可参考
- 标注渲染/选区交互 = 原版 Zotero reader（github.com/zotero/reader），需要时单独浅克隆
