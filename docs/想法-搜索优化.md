## 1. 工具：OpenSERP（多引擎搜索）

- 仓库：https://github.com/karust/openserp （官网 openserp.org，有托管云版 api.openserp.org）
- 自托管 SERP API + CLI：浏览器渲染抓 Google / Bing / Yandex / Baidu / DuckDuckGo / Ecosia
- **免 API key、无按次计费**，一条命令在 localhost 起 REST 服务；Python/Go 客户端
- 缓存、限流、异步；多引擎可互备（一个被反爬就换）
- 整合思路（届时评估）：本地 docker/进程起服务 → web_search 工具改为打 localhost REST；
  或多引擎并发取并集。注意反爬封号风险与合规（自托管=用自己 IP 抓）
- ⚠️ 来源图片里的仓库名是 OCR 错字（upseknannaujtimes-hash/...，404），已纠正为 karust/openserp
